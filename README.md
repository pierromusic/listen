# Site PIERRO

1. Copiez vos images dans `images/` avec les noms exacts indiqués dans `data/config.js`.
2. Modifiez liens, spectacles et courriel dans `data/config.js`. Rien d’autre à toucher.
3. Dépôt GitHub : envoyez tout le contenu de ce dossier à la racine du dépôt.
4. Settings → Pages → Branch: `main` → `/ (root)` → Save.
5. Pour les pubs : utilisez `https://votre-site/#promo` comme lien de destination.
